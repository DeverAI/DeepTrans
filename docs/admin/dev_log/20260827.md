# DeepTrans - 版本更新文档

## 20260827 - 第二轮：v1.4.0 发布准备（机翻 AI 兜底 + 脱敏发布包）

### 版本概述
**版本号**：v1.4.0（发布准备完成，上传由用户手动执行）
**主要目标**：国内机翻引擎评估、机翻失败回落 AI、完整检修、脱敏发布包构建

### 新增
- mech_ai_fallback 配置（默认开）：机翻引擎全失败后自动用当前 AI 引擎兜底；设置页行为页新增开关；i18n 双语键
- 机翻引擎尝试看门狗：每引擎 12s 守护线程硬限时（MECH_ATTEMPT_TIMEOUT），修复 getaddrinfo 不受 socket 超时约束导致的永久阻塞（faulthandler 定位证据：urllib3 create_connection 卡死）
- socket 默认超时收紧至 8s（DNS/TLS 分段累计可控；正常网络亚秒级不受影响）
- config.example.json 密钥占位符版；.gitignore；LICENSE(MIT/DeverAI)
- 发布资产：DeepTrans-v1.4.0-win64.exe（62MB，build.py 增加 --exclude-module=PyQt5 解决多 Qt 绑定冲突）；DeepTrans_src_v1.4.0.zip（25 文件脱敏源码）；RELEASE_NOTES.md；UPLOAD_GUIDE.md（网页/git 双路线）

### 实测记录
- 国内免Key端点全线反爬：百度 transapi errno 1022 / basetrans 空 / 有道 aidemo errorCode 102 / 腾讯 405 —— 不发布未验证爬取式引擎
- 受限网络整链路 28.6s 收敛：mymemory 12s 超时 -> google 12s 超时 -> AI 兜底正确返回译文
- 全量检修回归绿：编译/损坏配置/双模式冒烟/悬浮窗微测/端到端/i18n核对

### 决策与用户指示
- 仓库 DeverAI/DeepTrans 设为 Public；用户自行手动上传（本机 github/google/pypi 全超时、无代理监听，通道不可用）
- 发布内容：README/Design/Techniques/LICENSE/config.example.json/源码；内部协作文档（Fact/Future/FreqErr/dev_log/updates/AGENT.txt/todo/done）不入库
- 用户 ghp_ token 在会话中暴露，已在指南中建议立即撤销

### 影响范围
- core/translator.py、core/config.py、gui/settings.py、core/i18n.py、config.json（新增 mech_ai_fallback）、build.py（PyQt5 排除）
- 新增仓库文件：config.example.json、.gitignore、LICENSE
- 不影响：双 AI 引擎、悬浮窗、热键、托盘等既有行为

## 20260827 - 第一轮：v1.3.0 双 AI 引擎升级与全量真机验收

### 版本概述
**版本号**：v1.3.0
**发布日期**：2026-08-27
**版本类型**：功能升级 + 缺陷修复 + 真机验收
**主要目标**：落地双 AI 翻译引擎（小米 MiMo 默认 / DeepSeek 备用）、建立自动存错机制、实现命令行参数、修复遗留缺陷并完成真机验收

### 本轮新增功能

#### 1. 双 AI 翻译引擎
- AI_PROVIDERS 表驱动定义（core/config.py）：xiaomi（https://token-plan-cn.xiaomimimo.com/v1，mimo-v2.5/v2.5-pro/v2-pro）与 deepseek（chat/reasoner）
- translator 按 provider 装配 openai 客户端，客户端签名变化才重建；AI 请求统一 30 秒超时
- 设置窗口新增"AI 引擎"下拉（切换联动刷新模型列表）与两家独立密钥输入框
- 密钥策略（用户指定）：config.json 原有 deepseek_api_key 保持原样不动，仅新增 xiaomi_api_key 字段

#### 2. Err.log 自动存错机制
- 新增 utils/errlog.py（log_error/log_warning/log_exception，时间戳 + 完整堆栈追加写入）
- main.py 安装 sys.excepthook 全局钩子；core/errors.py 分析错误即落盘；translator/config 关键失败路径同步落盘
- 路径规则：开发态仓库根目录、冻结态 exe 同级目录；写日志自身绝不抛异常

#### 3. 命令行参数
- 实现 --config PATH / --debug / --no-tray / --portable（README 此前承诺但未实现的契约兑现）
- --config/--portable 在模块导入期解析，保证 cfg 单例创建前配置路径已确定

#### 4. 模块开关机制
- gui/tray.py 源码级 ENABLE_TRAY 开关；配合运行时 --no-tray 形成双通道关闭能力

### 本轮修复的问题
1. i18n 英文界面渲染出原始键名（text_color/bg_color 缺键）
2. 机械翻译对默认语言对必失败：MyMemory 收到小写 en-us 或裸 zh 直接抛语言不支持
3. 机翻端点不可达时请求无限悬挂（requests 无超时），Worker 卡死
4. 机翻 except 分支调用未导入符号导致 NameError（except 处理路径自身崩溃）
5. 图标/配置相对路径在换目录与 PyInstaller 场景失效
6. 恢复默认误清空 API 密钥
7. styles.py 导入期生成冗余常量；build.py 打包注入不存在的模块
8. README 多处虚构承诺（build.spec、LICENSE、命令行参数）与现实不符
9. dev_log 存在同日重复文件（单套制违规）
